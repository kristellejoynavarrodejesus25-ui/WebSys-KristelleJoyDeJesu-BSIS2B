## Weekly Summary

### Week 1 - HTML Fundamentals
Implemented the core document boilerplate, structured headings, text formatting, and foundational page layout.

### Week 2 - Semantic & Multimedia
Utilized HTML5 semantic elements alongside embedded multimedia media files with proper asset linking.

### Week 3 - CSS Basics
Linked external stylesheets, styled typography and color schemes, and applied box model positioning and layout styling.

### Week 4 - JavaScript Basics and DOM Manipulation
Developed dynamic DOM interactions including a real-time digital clock, interactive task list, and theme toggling.

### Week 5 - Javascript Functions and Bootstrap
Built a responsive website leveraging Bootstrap 5 grid layouts, an image carousel, and structured service cards.

### Week 6 - API & Client Storage
Integrated multiple external APIs (GitHub API, Weather API, Google Maps) and persistent client-side data handling using localStorage.

### Week 7 - MiniFullStackStarter
Created and deployed a full-stack CRUD application using Express and MongoDB.
Live Render Link: https://it-112-week7-fullstackstarter.onrender.com
